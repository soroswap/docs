---
title: "Execute Quotes From Your Contract"
description: "Turn a /quote response into Aggregator v3 routes and settle it from your own Soroban contract or transaction, instead of using /quote/build."
---

Most integrations call `/quote`, then `/quote/build`, and have the user sign the XDR. Use this page when you **build the transaction yourself**: your own router contract settles the trade, or you need the swap as one step inside a larger transaction.

The quote is priced for [Aggregator v3](/aggregator/technical-reference/contracts/aggregator-v3) on mainnet, `CARVQXFP4JF5ELLXUMQ6DALR346YVGBMQOHB4ENA7SSVXAYABXLBDDC4`. Execute it there.

<Warning>
  Do not execute `/quote` responses through the deprecated aggregator `CAYP3UWLJM7ZPTUKL6R6BFGTRWLZ46LRKOXTERI2K6BIJAWGYY62TXTO`. Routes can mix venues and include SushiSwap or Comet pools, which that contract cannot run.
  If you settle a v3 quote there, the trade takes a different path from the one that was quoted, and the output can be well below `amountOut`.
</Warning>

## 1. Ask for a quote the contract can execute

```bash
curl -X POST "https://api.soroswap.finance/quote?network=mainnet" \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "assetIn": "CCW67TSZV3SSS2HXMBQ5JFGCKJNXKZM7UQUWUZPUTHXSTZLEO7SJMI75",
    "assetOut": "CBI7UCH5KGSVQRO5H4SUCZUTZABCITZLRHQQZTWL2TK4RZ72TAR6IHRV",
    "amount": "10000000",
    "tradeType": "EXACT_IN",
    "protocols": ["soroswap", "aqua", "sushi", "comet"],
    "slippageBps": 100
  }'
```

**Leave `sdex` out of `protocols`.** An SDEX quote (`"platform": "sdex"`) is a classic path payment, and the aggregator contract cannot settle it.

## 2. Map the response to `swap_exact_in`

| Contract argument | From the quote |
|---|---|
| `amount_in` | `amountIn`. This is the gross amount, fee included. |
| `min_out` | `otherAmountThreshold`, which already includes your `slippageBps`. |
| `routes[i].amount_in` | `rawTrade.distribution[i].share`. The shares add up to `amountIn` minus the fee. |
| `routes[i].hops` | `rawTrade.distribution[i].hops`, one typed `Hop` per entry (see below). |
| `partner` | `None`, unless your key has a partner rate. In that case pass the same `Partner { id, bps }` that `GET /partner` returns, otherwise the shares will not add up. |

Each element of `hops` describes one pool:

```json
{ "protocol": "sushi", "poolId": "CDMJ…JBVCT", "tokenIn": "CCW6…MI75", "tokenOut": "CBI7…IHRV",
  "amountIn": "9990000", "amountOut": "973043293419438491", "feeBps": 5 }
```

Aquarius hops also carry `poolHash`.

<Note>
  Read the venues from `hops`, not from `protocol_id` or `path`. Since August 2026 one route can cross several venues (for example Aquarius, then SushiSwap). `protocol_id` only names the first hop's venue, and `path` lists only the tokens.
</Note>

## 3. Encode the routes

This TypeScript turns `rawTrade.distribution` into the `routes` argument. It was tested on mainnet against SushiSwap, Aquarius (constant-product and concentrated pools), mixed Aquarius-then-SushiSwap routes and multi-route splits.

```ts
import { Address, BASE_FEE, Contract, Networks, TransactionBuilder, nativeToScVal, rpc, scValToNative, xdr } from "@stellar/stellar-sdk";

const server = new rpc.Server("https://mainnet.sorobanrpc.com");
type Hop = { protocol: string; poolId: string; tokenIn: string; tokenOut: string; poolHash?: string };
type Entry = { share: string; hops: Hop[] };

const addr = (a: string) => new Address(a).toScVal();
const sym = (s: string) => xdr.ScVal.scvSymbol(s);
const struct = (f: Record<string, xdr.ScVal>) =>
  xdr.ScVal.scvMap(Object.keys(f).sort().map((k) => new xdr.ScMapEntry({ key: sym(k), val: f[k] })));
const variant = (name: string, payload: xdr.ScVal) => xdr.ScVal.scvVec([sym(name), payload]);

/** Binary ScAddress order, which is what Aquarius sorts by. Not string order. */
const byAddress = (a: string, b: string) =>
  Buffer.compare(new Address(a).toScAddress().toXDR(), new Address(b).toScAddress().toXDR());

/** Read-only contract call through simulation. */
async function view(contract: string, fn: string, source: string): Promise<any> {
  const tx = new TransactionBuilder(await server.getAccount(source), { fee: BASE_FEE, networkPassphrase: Networks.PUBLIC })
    .addOperation(new Contract(contract).call(fn))
    .setTimeout(30)
    .build();
  const sim = await server.simulateTransaction(tx);
  if (rpc.Api.isSimulationError(sim)) throw new Error(`${contract}.${fn}: ${sim.error}`);
  return scValToNative(sim.result!.retval);
}

async function toRoutes(distribution: Entry[], source: string): Promise<xdr.ScVal> {
  const routes: xdr.ScVal[] = [];
  for (const entry of distribution) {
    const hops: xdr.ScVal[] = [];
    let aquaSteps: xdr.ScVal[] = [];
    let aquaIn = "";
    const flushAqua = () => {
      if (aquaSteps.length === 0) return;
      hops.push(variant("Aqua", struct({ token_in: addr(aquaIn), steps: xdr.ScVal.scvVec(aquaSteps) })));
      aquaSteps = [];
    };
    for (const h of entry.hops) {
      if (h.protocol === "aqua") {
        // Consecutive Aquarius pools become one AquaHop with several steps.
        if (aquaSteps.length === 0) aquaIn = h.tokenIn;
        const tokens = ((await view(h.poolId, "get_tokens", source)) as string[]).sort(byAddress);
        aquaSteps.push(
          xdr.ScVal.scvVec([
            xdr.ScVal.scvVec(tokens.map(addr)),
            xdr.ScVal.scvBytes(Buffer.from(h.poolHash!, "hex")),
            addr(h.tokenOut),
          ]),
        );
        continue;
      }
      flushAqua();
      const base = { token_in: addr(h.tokenIn), token_out: addr(h.tokenOut) };
      switch (h.protocol) {
        case "soroswap":
          hops.push(variant("Soroswap", struct({ pair: addr(h.poolId), ...base })));
          break;
        case "sushi": {
          const token0 = (await view(h.poolId, "token0", source)) as string;
          hops.push(variant("Sushi", struct({ pool: addr(h.poolId), ...base, zero_for_one: xdr.ScVal.scvBool(h.tokenIn === token0) })));
          break;
        }
        case "comet":
          hops.push(variant("Comet", struct({ pool: addr(h.poolId), ...base })));
          break;
        case "phoenix":
          hops.push(variant("Phoenix", struct({ pool: addr(h.poolId), ...base })));
          break;
        default:
          throw new Error(`unsupported venue ${h.protocol}`);
      }
    }
    flushAqua();
    routes.push(struct({ amount_in: nativeToScVal(BigInt(entry.share), { type: "i128" }), hops: xdr.ScVal.scvVec(hops) }));
  }
  return xdr.ScVal.scvVec(routes);
}
```

`toRoutes` makes one read per Aquarius and SushiSwap hop, to fetch the pool's token set and `token0`. Both are fixed per pool, so cache them.

The call itself:

```ts
const routes = await toRoutes(quote.rawTrade.distribution, user);
const op = new Contract("CARVQXFP4JF5ELLXUMQ6DALR346YVGBMQOHB4ENA7SSVXAYABXLBDDC4").call(
  "swap_exact_in",
  addr(user),
  addr(quote.assetIn),
  nativeToScVal(BigInt(quote.amountIn), { type: "i128" }),
  addr(quote.assetOut),
  nativeToScVal(BigInt(quote.otherAmountThreshold), { type: "i128" }),
  routes,
  xdr.ScVal.scvVoid(), // partner: None
);
```

Simulate, assemble, sign and submit it like any other Soroban transaction. To make the same call from a Soroban contract, including the token authorization a contract caller needs, see [Cross-Contract Integration](/aggregator/technical-reference/cross-contract-integration).

## Things that break a settlement

- **`BadRoute` (error 5).** The shares do not add up to `amount_in - fee`. Usually the `amountIn` was changed after quoting, or the `partner` argument does not match the rate the quote was priced with.
- **`InsufficientOutput` (error 7).** The pools moved between quote and execution by more than your slippage. Re-quote.
- **A Sushi hop fails inside the pool.** `zero_for_one` is wrong. It must be `tokenIn == pool.token0()`.
- **An Aquarius hop fails.** The step's token set is not sorted by `Address` order, or the pool hash does not belong to that token set.
- **The quote is stale.** Quotes reflect pool state when they are made. Execute promptly, and treat `otherAmountThreshold` as your guarantee, not `amountOut`.
