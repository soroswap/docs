# Aggregator

The aggregator is a smart contract that routes trades across multiple liquidity sources to find the best price.

## How it Works

When a user swaps tokens, the aggregator queries all configured AMMs simultaneously and selects the route that provides the best output amount.

## Liquidity Sources

The aggregator currently integrates with AMMs deployed on the Soroban-Stellar Mainnet:

- **Soroswap** - The native AMM protocol
- **Phoenix Protocol** - Phoenix Protocol AMM
- **Aqua** - Aqua AMM

## Supported Trades

The aggregator supports swaps between any token pairs that have liquidity on at least one of the integrated AMMs.
