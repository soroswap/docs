# Media Kit

Welcome to the Soroban Media Kit. Here you'll find resources to help you spread the word about Soroban and the Stellar ecosystem.

## About Soroban

Soroban is Stellar's smart contract platform, enabling developers to build decentralized applications with Rust-based smart contracts. It provides a secure, scalable, and cost-effective environment for creating on-chain applications.

### Key Features

- **Rust-based smart contracts** – Leverage Rust's safety and performance
- **Low transaction costs** – Fraction of a cent per operation
- **Fast finality** – 5-second settlement times
- **WebAssembly (Wasm) runtime** – Portable and efficient contract execution
- **Decentralized oracle support** – Bring real-world data on-chain
- **Full composability** – Interact with existing Stellar assets and protocols

## Usage Guidelines

### Do's

- Use the official logo files provided in this kit
- Maintain proper clear space around logos
- Use approved color variations only
- Scale logos proportionally to maintain quality

### Don'ts

- Modify, distort, or rotate logos
- Use unofficial color variations
- Remove clear space requirements
- Use low-resolution or pixelated assets
- Combine logos with other brands without permission

## Clear Space

Always maintain a minimum clear space around the Soroban logo equal to the height of the "S" in the logo.

![Clear Space Diagram](/img/soroban-clear-space.png)
