[Aggregator v3](/aggregator/technical-reference/contracts/aggregator-v3) is the contract the Soroswap API settles every Soroban swap through on mainnet. It runs typed routes hop by hop across Soroswap, Aquarius, SushiSwap V3, Comet and Phoenix. There is no adapter registry: each venue is compiled into the contract, and callers name the pools in each hop.

## Deprecated: the adapter-based aggregator

The original aggregator, `CAYP3UWLJM7ZPTUKL6R6BFGTRWLZ46LRKOXTERI2K6BIJAWGYY62TXTO`, reached each protocol through an adapter contract (Soroswap, Phoenix, Aqua and Comet). The API stopped using it on 2026-09-24. These pages are kept for reference:
